# Ideal Course Mapping

## Overview

Ideal Course Mapping is a flexible, responsive system to aid in course planning, demand anticipation, and pathway visualization for students and advisors. This project uses a Python Flask backend and a React frontend. 

## Features

- **Backend**: Flask (Python)
  - RESTful API endpoints
  - JSON responses

- **Frontend**: React (JavaScript)
  - Dynamic user interface
  - API calls to the Flask backend

## Prerequisites

Before you begin, make sure you have the following installed:

- Python 3.x
- Node.js and npm (Node Package Manager)
