# IdealCourseMapping: Backend

This directory contains the backend implementation of the **IdealCourseMapping** project. It includes server-side logic, API endpoints, and database integration to power the application's functionality.

## Main Folders

The backend folder contains the following key subdirectories:

- **`Scripts_for_frontend`**: `Scripts that will be used when the server is running`  
- **`Pre_reqs_work`**: `Files used during prereq work`  
- **`Majors_work`**: `Files used during work for making files for frontend`  
- **`Frontend_files`**: `Files used by frontend and scripts`  

### To install the needed packages for the main script: 
- Have Python3 installed on the computer 
- Install the python package pipreqs by doing "pip install pipreqs" 
- Run the **RUN_ME_FOR_PACKAGE_INSTALLATION.py** script
